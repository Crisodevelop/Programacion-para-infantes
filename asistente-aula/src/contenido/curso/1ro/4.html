Decisiones: if / elif / else

Vas a decidir con if, elif y else: acertaste, más alto o más bajo.

Teoría · La idea · 1 – 3 min

Todos · escuchamos

¿Qué es una decisión?

Un if revisa una condición: si es verdadera hace una cosa; si no, el else hace otra.

En la vida real

Si llueve, llevo paraguas; si no, llevo gorra. En el juego: si acertaste, ganas; si no, sigues.

Teoría · Las partes · 3 – 5 min

Las partes de una decisión

  1. if condición:Pregunta algo que solo puede ser verdadero o falso.
  2. ==Compara si dos valores son iguales. Un solo = guarda.
  3. Dos puntos y sangríaLo que va dentro del if se corre a la derecha.
  4. else:Lo que pasa cuando la condición es falsa.

Así se escriben ✓

  1. edad = 15
  2. if edad >= 18:
  3. display("Entras")
  4. else:
  5. display("Todavía no")

Teoría · ¿Lo entendí? · 5 – 8 min

Tú solo · en tu compu

Te quedan 3 vidas. Con if vidas == 0: display("Game Over"), ¿sale Game Over?

El if solo entra cuando vidas vale 0. Con 3 la condición es falsa y se la salta.

Todos · a mano alzada

¿Qué hace == en Python?

= guarda y == compara. if intento == secreto: pregunta si los dos son iguales.

¿Qué muestra?

  4. display("¡Acertaste!")
  5. else:

  1. if intento ___ secreto:

== pregunta si son iguales. Un solo = guarda y aquí da error; != es justo lo contrario.
